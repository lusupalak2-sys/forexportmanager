สำรอง / กู้คืนข้อมูล

ข้อมูลทั้งหมดเก็บไว้ในเบราว์เซอร์ของอุปกรณ์นี้เท่านั้น แนะนำให้ Export เก็บไว้เป็นระยะ

Export Excel — ไฟล์ .xlsx แยกเป็นชีท VPS, Portfolio, EA, Daily Log และ Summary เปิดดูหรืออัปโหลดเข้า Google Sheets ได้ทันที (Google Drive → New → File upload หรือเปิดใน Google Sheets app แล้วเลือกไฟล์)
Export JSON — ใช้สำหรับ Import กลับเข้าแอปนี้เพื่อกู้คืนข้อมูลทั้งหมดแบบเป๊ะๆ

วิธีติดตั้งบน iPad

  1. เปิดไฟล์นี้ด้วย Safari
  2. แตะปุ่ม แชร์ (กล่องมีลูกศรชี้ขึ้น)
  3. เลือก "เพิ่มไปยังหน้าจอโฮม"
  4. เปิดแอปจากหน้าจอโฮมได้เหมือนแอปทั่วไป
